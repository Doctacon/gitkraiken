## Interim lesson: normal commit scope reset

The work accumulated safety infrastructure and installer concerns while leaving a
core daily action unavailable. The operator explicitly reset the scope to restoring
ordinary commits. Keep a working end-to-end core as the unit of progress; do not
make the entire roadmap or unrelated distribution redesign a prerequisite.

Real terminal evidence mattered: the process-group safety fix broke `/dev/tty`
hooks. A bounded foreground handoff plus Textual suspension fixed that without
removing the index/descendant protections. Automated non-headless 80×24 refusal/
draft/success and real disposable-key SSH signing provide stronger evidence than
headless UI plus noninteractive signer doubles alone. These remain local automated
proofs, not release/human/platform certification.

## Interim lesson: bounded M1 completion work

The later authorization included dedicated acceptance cases. Current/minimum Git
composer tests and real terminal journeys are now evidence, not inferred coverage.

Keep increments below the operator's 15-minute ceiling. A broad run found failures
quickly; interrupting it and partitioning all collected cases was better than a long
opaque wait. Preserve failed logs and rerun the entire failed partition before
calling that partition green.

Screenshots caught clipped controls that presence-only tests missed. The Activity
Close button was inside the screen but outside its parent content; test actual
hit-tested boundaries and clicks. Live Textual label changes also need layout
invalidation when an ASCII fallback becomes wider.

Measure before optimizing: eliminating a duplicate snapshot materially improved
refresh without weakening post-fetch reconciliation. Keep the residual startup
miss explicit; do not redefine targets or change history semantics to manufacture
acceptance. Similarly, distinguish baseline formatter debt, prepared CI, automated
terminal checks and real-user/platform acceptance. M1 remains unaccepted and M2
has not started.
